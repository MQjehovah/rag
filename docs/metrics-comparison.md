## 关键结论

### 1. v1 检索链路稳定（W1 = W12）
- Page Recall@5/10、引用准确率 **完全一致**（18.6% / 30.0% / 6.2%）——v1 检索代码 12 周未改，符合预期。
- 平均响应从 10450ms → 3097ms（服务状态/缓存因素，非功能性优化）。

### 2. v2 依赖 KO 审核覆盖（W8 = W12）
- KO Recall@5/10 恒为 **7.1%**，审判通过率 14.3% → 10.0%。
- **根因**：published KO 仅 9-10 个，覆盖不了 70 题。v2 检索只查 published KO，审核覆盖不足是检索发力的**前置条件**。

### 3. "不确定"导向正确工作
- 不确定率 85.7% → 90%：缺证据/冲突时正确拒答，而非错答。这是知识审判层（W7）的核心价值——"不确定比错答更可信"。
